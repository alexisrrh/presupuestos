# Hoja de ruta

Esta hoja es una base creada a partir del encargo de fase 1A.

1. Fase 0: estabilización de presupuestos y guardado de estado.
2. Fase 1A: documentación, roles protegidos, separación de acceso y borrador SQL pendiente de prueba local.
3. Fase 1B: demostración local de fichas de trabajadores; la integración, selección explícita de organización y cuentas autorizadas quedan pendientes.
4. Fase 2: fichajes y correcciones trazables.
5. Fase 3: informes, preparación de nóminas y recordatorios.
6. Fase 4: licitaciones, obras, documentos preventivos, costes y auditoría.

No se inicia una fase posterior hasta verificar las pruebas y limitaciones de la anterior.
