# Alcance acordado de PRITECA Gestión

Esta es una base creada a partir del encargo de fase 1A; no es una copia de la especificación funcional v1.1, que no se recibió.

El producto conserva presupuestos y añade progresivamente propietario, administrativo y empleado. Las cuentas de empleado serán creadas por personal autorizado y el acceso futuro por DNI/NIE y contraseña se resolverá mediante servidor, nunca desde el navegador con privilegios.

Fases futuras: fichajes, pausas, historial y correcciones trazables; anulación justificada de jornadas; informes y preparación mensual de nóminas sin prometer netos definitivos; licitaciones por expediente, documentos, requisitos, versiones, plazos y justificantes; obras, documentación laboral/preventiva, costes y auditoría.

Los recordatorios futuros tratarán incidencias de fichaje con aviso inicial y correo al alcanzar tres jornadas programadas sin fichar o una incidencia con esa antigüedad. Excluirán descansos y ausencias registrados y cesarán cuando el trabajador responda. No completarán jornadas ni aplicarán descuentos automáticamente. Los correos reales se separarán del usuario técnico. Las copias deberán ser recuperables para base de datos y archivos.
